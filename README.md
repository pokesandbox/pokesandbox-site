# pokesandbox-site

Temporary Under construction page for [pokesandbox.com](https://pokesandbox.com), served by GitHub Pages from the root of `main`. It stays up until the webapp is hosted.

The page was copied from `site/` in the private `pokesandbox` repo. The banners in `assets/` come from `docs/design/assets/`, and `assets/tokens.css` from `docs/design/authoring-mockups/assets/`. When those change there, copy them here again.

Open it locally with any static server from the repo root, for example `python3 -m http.server`, since the page uses root-relative paths.
